# Rusenbuschita -> `Rusenbuschita_PPL` / `Rusenbuschita_XPL`

Fuente: https://www.alexstrekeisen.it/english/pluto/rosenbuschite.php

## PPL (luz polarizada plana)
- 
Habits:
Prismatic to acicular, radial fibrous, feltlike, massive.

- 
Color:
Usually pale yellow.


## XPL (nicoles cruzados)
- 
Birefringence:
Low, II order.

Hildegard Wilske
